Quản lý cửa hàng, gọn và dễ dùng.

Ba phần mềm cho ba loại cửa hàng. Chạy trên Windows, tải về cài là dùng.

Cách cài đặt

  1. Bấm nút tải phiên bản bạn cần.
  2. Mở file vừa tải. Nếu Windows báo chặn, chọn Thông tin thêm rồi Vẫn chạy.
  3. Làm theo hướng dẫn trên màn hình.

Yêu cầu máy tính

  • Windows 10 hoặc 11, 64-bit
  • RAM từ 4 GB
  • Trống 500 MB ổ cứng

Kiểm tra file tải về

Mã SHA256 của mỗi bản nằm trong bảng trên. Mở PowerShell và chạy: certutil -hashfile TenFile.exe SHA256
