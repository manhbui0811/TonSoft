Phần mềm quản lý cửa hàng đẳng cấp, tinh gọn.

Giải pháp tối ưu cho từng mô hình kinh doanh bán lẻ, dịch vụ và F&B. Chạy mượt mà trên Windows, cài đặt nhanh chóng.

Hướng dẫn sử dụng

  1. Chọn phần mềm và phiên bản bạn muốn, sau đó bấm nút tải về.
  2. Giải nén hoặc đặt file thực thi vào một thư mục riêng biệt trên máy tính (ví dụ: C:\TonSoft\).
  3. Mở file trực tiếp. Nếu Windows hiển thị cảnh báo bảo mật, chọn Thông tin thêm rồi chọn Vẫn chạy.

Yêu cầu hệ thống

  • Hệ điều hành Windows 10 hoặc 11 (64-bit)
  • Bộ nhớ RAM tối thiểu từ 4 GB
  • Dung lượng trống ổ cứng khoảng 500 MB
  • Yêu cầu Microsoft Edge WebView2 Runtime (thường có sẵn trên Windows 11 và phần lớn Windows 10; nếu thiếu, tải tại đây)

Xác thực tính bảo mật của tệp

Mã băm SHA256 của từng phiên bản được cung cấp trực tiếp trong bảng chi tiết phía trên. Bạn có thể sử dụng PowerShell để kiểm tra bằng lệnh: certutil -hashfile TenFile.exe SHA256.
