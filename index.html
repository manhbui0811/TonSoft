Quản lý cửa hàng, gọn và dễ dùng.

Bộ phần mềm quản lý dành cho cửa hàng Việt. Dễ sử dụng, đầy đủ tính năng cần thiết và dữ liệu được lưu ngay trên máy tính của bạn.

Cách dùng

  1. Chọn phần mềm phù hợp và bấm Tải phiên bản mới nhất.
  2. Đặt file vào một thư mục riêng, ví dụ C:\TonCoffee\. Phần mềm là một file duy nhất, không cần cài thêm .NET.
  3. Mở file. Nếu Windows báo chặn, chọn Thông tin thêm rồi Vẫn chạy.

Yêu cầu máy tính

  • Windows 10 hoặc 11, 64-bit
  • RAM từ 4 GB
  • Trống 500 MB ổ cứng
  • Microsoft Edge WebView2 Runtime (Windows 11 và hầu hết Windows 10 đã có sẵn, nếu máy báo thiếu thì tải tại đây)

Kiểm tra file tải về

Sau khi tải, bạn có thể kiểm tra file bằng mã SHA256 do TonSoft cung cấp khi cần.
